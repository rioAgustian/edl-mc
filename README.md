# Electric Double Layer Simulator

Live Metropolis Monte Carlo of ions next to a charged electrode (1D lattice of charged planes), compared with Gouy-Chapman theory: concentration profiles, potential, Debye length, Grahame equation and the contact value c_tot(0).

Open the page: https://rioagustian.github.io/edl-mc/

Same model as the Lab 5 notebook of *Modelling of Materials Interfaces*: 80 planes of 0.1 nm, A = 40 x 40 nm², 1:1 salt in water (ε = 80). A single static HTML file (`index.html`), no build step or dependencies.
